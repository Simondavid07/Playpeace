# PlayPeace

Free music website and free ringtone downloader — Spotify-style, black-and-white theme.

- Trending songs, Popular artists, Popular albums
- World Music Library: Bollywood, Hollywood, Spanish, Punjabi, South Cinema, K-Pop, Haryanvi
- Golden Era: 1950s–2010 (Kishore Kumar, Mohammed Rafi, R. D. Burman, Lata Mangeshkar, Asha Bhosle, Mukesh…)
- Worldwide search (iTunes catalog)
- MP3 download of song previews for ringtones

## How to run

Open `index.html` in a browser, or serve the folder with any static host / GitHub Pages.

## Important — previews only

Songs on PlayPeace play as **licensed 30-second previews** from the Apple iTunes catalog.
No full copyrighted songs are included in this repo — uploading them would be piracy.
Local artwork/video assets are not included in this GitHub export; the page falls back
to remote iTunes artwork where a local file is missing.
